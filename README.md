# WallMonk 🎨

WallMonk is a sleek, modern wallpaper application built with **Flutter**. It provides users with high-quality, curated wallpapers to personalize their devices with ease.

## 🚀 Current Project Status: Closed Testing
WallMonk is currently in the **Closed Testing phase** on the Google Play Store. We are fine-tuning the performance and squashing bugs before the official public release. Stay tuned for the production launch!

---

## 🛠️ Features
* **High-Res Collection:** A vast library of stunning wallpapers.
* **Categories:** Organized themes to suit every mood.
* **Smooth UI:** Built with Flutter for a high-performance, native feel.
* **Favorites:** Save the walls you love for quick access.
* **Downloads:** Download the walls you love in your local storage.

## 💻 Getting Started

Follow these steps to get a local copy of the project up and running on your machine.

### Prerequisites
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (Stable channel)
* [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/)
* Dart SDK

### Installation
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/saurabh-zz007/wallMONK.git](https://github.com/saurabh-zz007/wallMONK.git)
    cd wallMONK
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the app:**
    Connect your physical device or start an emulator, then run:
    ```bash
    flutter run
    ```
